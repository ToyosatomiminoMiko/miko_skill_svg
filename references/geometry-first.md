# 几何优先:怎么把一张图拆成简单图元

这份文档解决“从目标图到 SVG 元素”的中间步骤:先决定**用什么图元**,再决定坐标参数。
顺序反了就会滑向“一条 path 手写几十个坐标”,图能看但改不动、也看不出原意。

## 1. 拆图元清单

对着一张目标图,先把每个可见形状标成下面之一:

| 类别 | 判断依据 | 元素 |
| --- | --- | --- |
| 轴对齐矩形 | 四条边水平/竖直 | `<rect>` |
| 圆角矩形 | 矩形 + 四角圆弧 | `<rect rx ry>` |
| 圆 / 椭圆 | 到中心等距 / 两轴半径 | `<circle>` / `<ellipse>` |
| 直线段 | 两点 | `<line>` |
| 开放折线 | 一串点,不闭合 | `<polyline>` |
| 闭合多边形 | 一串点,首尾相连 | `<polygon>` |
| 规则多边形 / 星形 | 顶点按固定角度均布 | `regular_polygon` / `regular_star` → `<polygon>` |
| 45° 等腰梯形 / 箭头(chevron) | 底角 45°,两条腰一横一竖 | `<polygon>` + `chevron()` 配方(见下) |
| 圆弧段 | 一段圆周 | `<path d="M... A...">` |
| 透镜/叶片 | 两条同半径弧围成的尖头形 | `lens_path_d` → `<path>` |
| 由若干简单形叠加成的复合形 | 同色图形叠起来 | 拆成多个图元,靠绘制顺序取并集 |
| 真自由曲线 | 无法用圆弧/多边形描述 | `<path>` 贝塞尔(最后手段) |

拆完之后,把“重复出现的形状”标出来(麦穗、齿、花瓣、星角……),它们一定要参数化。

## 2. 坐标模型

三个决定,先定死再画:

1. **单位**:默认 1 用户单位 = 1 px,`viewBox` 与宽高一致。需要物理尺寸时在根元素写
   `width="100mm"` 之类,但 `viewBox` 仍用一套纯数字坐标。
2. **原点**:每个部件用**自己的局部原点**(圆心/结中心/质心),拼装时用 `<g transform>`
   平移+缩放。不要把部件坐标预先乘成画布坐标——那样一个参数改动就要重算全图。
3. **y 轴**:SVG 屏幕坐标 y 向下,角度约定为 0° = 正右、角度增大 = 屏幕顺时针。
   本库的 `geom` 全部遵守这个约定;写自己的公式时不要混用数学坐标系。

> 半像素坑:如果参数是从位图逐像素量出来的,注意“像素中心 = 整数索引(numpy)”与
> “像素中心 = i+0.5(SVG 光栅化)”差半个像素。不同部件可能用不同约定,
> 拼装时按部件分别修正,不要全局加 0.5。

## 3. 常见几何配方

### 正多边形与星形

```python
from svgkit.geom import regular_polygon, regular_star
hexagon = regular_polygon(cx, cy, r, 6, phase_deg=30)      # phase 让尖角朝上
star = regular_star(cx, cy, r_outer, r_inner, 5, phase_deg=-90)
```

星形内外半径比决定角尖锐度;`phase_deg` 决定第一个外顶点方向,尖角朝上就用 `-90`。

### 齿轮(齿圈)

齿轮 = 齿根圆 + 齿顶圆 + 若干齿。单个齿的侧边从“齿根圆上的半角”到“齿顶圆上的半角”,
齿顶两角用圆弧倒圆。参数:齿数、齿位角、根半径、顶半径、根半角、顶半角、倒圆半径。
画法:按齿位角逐个生成齿的外轮廓点列,拼成一圈 `<polygon>`;内孔用单独的圆/圆弧。
如果齿圈要被别的图形“压断”(缺口),优先**按缺口边界把齿圈拆成多块简单多边形**,
而不是用 `<mask>` 或带洞复合 path——拆开后每块仍可单独编辑、选中、改色。

### 圆弧带(芒 / 放射线)

一条“同心圆弧带”的几何是:圆心 + 半径范围 `[r_inner, r_outer]` + 起止角。
可以用描边圆弧表达:`<path d="M.. A..">`, `stroke-width = r_outer - r_inner`,
`stroke-linecap="round"`。圆头端点要埋进相邻图形里,否则会在尖端露头
(把终点角往图形内部多转几度)。

### 麦粒 / 花瓣(沿圆弧弯的厚片)

1. 在半径 `R` 的圆弧上取一段中心线,按角度采样点列;
2. 每个采样点沿法向两侧各偏移 `thickness/2`(厚度可以沿长度渐变);
3. 两侧点列首尾相接成闭合多边形。
两粒之间留角度缝;整组再绕圆心镜像/旋转出对称的另一半。

### 45° 等腰梯形 / chevron(一圈箭头)

“一圈箭头”“雪佛龙环”这类图,每一块都是**等腰梯形,底角 45°**:两条底边都在 45° 方向上,
两条腰一条平行、一条垂直于整体对称轴。不要当成自由多边形手写坐标,用 5 个参数:

- `apex`:顶点;`rot`:朝向(0°=上, 90°=右, 180°=下, 270°=左, 对角线用 ±45);
- `leg` = 臂厚 × √2 = 端面斜切边长 = 梯形两腰;
- `reach` = 顶点**沿对称轴**到臂末端面的轴向距离(不是臂长:臂长是 `reach·√2`);
- `gap` = 两根臂之间沿对称轴的折缝。

单根臂的 4 个角(局部坐标,chevron 指向上,side = ±1 为左右臂):

```
V1 = (side*gap/2,       gap/2)         顶点侧端面 × 外侧底
V2 = (side*gap/2,       gap/2 + leg)   顶点侧端面 × 内侧底
V3 = (side*(reach-leg), reach)         末端面 × 内侧底
V4 = (side*reach,       reach)         末端面 × 外侧底
```

再整体旋转 `rot`、平移到 `apex`。`gap == 0` 时两臂共边,直接输出合成后的 6 点 V 形
(顶点 → 右外底 → 右末端面 → 右内底 → 左内底 → 左末端面),否则共边处会露出抗锯齿细线。

一圈 4 个箭头 = **同一份几何绕中心每 90° 旋转**,常量里只写一份;对角朝向(西北等)
用 `rot=-45`,此时两臂正好变成水平/竖直的 “Γ” 形。参考实现:
项目目录 `__projects_python/img_gen/ogas/parts.py` 的 `chevron()`(出图脚本不入技能)。

### 对称与阵列

- 镜像:先算半边点列,再用 `geom.mirror(points, axis_x=...)`;不要手抄坐标后改符号。
- 阵列:同一份局部几何放进多个 `<g transform="rotate(...)">`,或按角度公式生成点列。
- 组合:多个同色图元叠在一起就是并集,不需要布尔运算;绘制顺序只影响可读性。

### 轮廓/地图类不规则多边形

从数据源采样成点列,做一次缩放+旋转+平移,直接 `<polygon>`。注意:
- 采样点写死在代码/常量里,不要运行时解析外部文件(输出才可复现);
- 太碎的细节在目标尺寸下是亚像素噪声,宁可少采点,别追求“像位图”;
- 轮廓如果有“人工补笔”的段落,单独注释说明,不要混在拟合参数里。

### 复合轮廓(必须挖洞时)

只有“必须在一个填充内挖一个真洞”时才用 `<path fill-rule="evenodd">`:一条 path 里
先写外轮廓子路径,再写内轮廓子路径。能拆成多块不重叠的多边形就优先拆。

## 4. 自检(结构层面,不做像素比对)

生成后按 `references/contract.md` 的清单做结构检查:
XML 合法、无外部引用、无脚本事件、重复生成逐字节一致、数字格式统一、每个部件有 id。
视觉是否满意由人打开 SVG 判断;本技能默认不做渲染比对和图像识别。

唯一例外:手上有参考位图时,允许按 `references/fitting-with-reference.md` 做**一次**数值自检(模型多边形自己光栅化后与位图色块比 IoU),用来抓方向/镜像/端点这类硬错误,不用于迭代逼近。
