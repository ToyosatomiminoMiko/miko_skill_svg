# SVG 输出契约

生成物要能被浏览器、Inkscape、VS Code 预览直接打开,并且**可编辑、可复现**。下面是
硬性要求与推荐做法。

## 根元素

```xml
<svg xmlns="http://www.w3.org/2000/svg" width="800" height="532" viewBox="0 0 800 532">
```

- 必须声明 `xmlns="http://www.w3.org/2000/svg"`;独立 `.svg` 文件没有它打不开。
- `width`/`height` 与 `viewBox` 保持一致(1 用户单位 = 1 px),缩放交给容器。
- 需要 `xlink`/`inkscape` 命名空间时才声明,不要无脑堆。
- 根上可以加 `<title>`/`<desc>` 做无障碍描述,但不要依赖它们表达图形。

## 禁止项

- 脚本:`<script>`、`on*` 事件属性、`javascript:` URL;
- `<foreignObject>`(嵌入 HTML);
- 外部引用:`<image href="http://...">`、外部 CSS、外部字体文件;
- 位图底图/追踪结果整块塞进 `<image>`;
- 滤镜/混合模式作为图形的主要表达手段(渲染器差异大,且不可编辑)。

## 数字格式(确定性)

- 一律走 `svgkit.serialize.fmt`:四舍五入 4 位小数、去尾随 0、整数不写小数点、
  `-0` 归一为 `0`;
- 不要用 `str(float)`(会出 `1e-05`、浮点尾噪声)或语言里的 `toFixed`(会对负数
  和进位产生不一致);
- 同一份参数重复生成必须逐字节一致。可以进版本库,也可以拿 `sha256` 当回归基线;
- 不要输出时间戳、随机 id、进程相关路径。

## 结构与可编辑性

- 每个语义部件一层 `<g id="...">`,id 用稳定的英文名(`wreath` / `gear` / `root` / `map`);
- 样式用表现属性(`fill` / `stroke` / `stroke-width` …),不要 `style="..."`;
- 能拆成简单图元的不要合并:一个 `<g>` 里若干 `<polygon>` 比一条大 `<path>` 好改;
- 变换用 `<g transform="translate(...) scale(...)">`,不要提前把变换乘进坐标
  (除非该坐标本身就是参数);
- 避免 `<mask>` / `<clipPath>` 当“几何切割”用:优先把形状真的拆开;
- 圆角矩形用 `<rect rx ry>`,不要采样成多边形;圆用 `<circle>`,不要用两段弧拼;
- 真圆弧用 `A` 命令并写清半径,不要用贝塞尔硬逼近整圆。

## 填色与描边

- 同色图形叠在一起靠绘制顺序取并集;若出现异色描边接缝,检查是否该用同色重叠
  (`stroke-linecap="round"` 的圆头端点要埋进相邻图形);
- 描边宽度单位是用户单位,缩放组里的描边会一起缩放;需要恒定线宽时把描边放在组外;
- `fill-rule` 只在复合 path 挖洞时使用,默认 `nonzero`;
- 渐变/图案用 paint server 表达:`<defs>` 里放 `<linearGradient>` / `<radialGradient>`
  (内层 `<stop offset stop-color>`),图元只写 `fill="url(#id)"`;不要用滤镜或多层
  半透明色模拟渐变 —— 前者跨渲染器差异大且不可编辑,后者改一处要改一批;
- 画布级背景用 `gradientUnits="userSpaceOnUse"` 且 cx/cy/r 写成画布像素;局部图形的
  渐变留默认 objectBoundingBox(0~1),随图形缩放。

## 文本

- 用 `<text>` + `font-family` 回退栈,不要用 `<image>` 或转曲后的 path 冒充文字
  (除非用户明确要求“文字转曲”);
- 不做自动测量/自动换行:锚点用 `text-anchor`,位置由调用方给;
- 字体不一致时以打开环境的回退结果为准,详见 `references/text-font.md`。

## 工程位置(脚本放哪)

- 技能内只放**可复用底座**(`scripts/svgkit/`、`scripts/fit.py`)与文档/内置范例;
- **具体某张图的脚本与产物放那张图的项目目录**,`build.py` 用 `sys.path` 引技能底座
  (见 `SKILL.md` 的“出图脚本放哪”);
- 不要把只画过一次的常量/点列塞进技能里当“范例”:技能要跟着底座升级,项目资产要跟着图走。

## 结构自检清单

1. 能被 XML 解析器解析(标签闭合、属性转义);
2. 没有上面“禁止项”;
3. 两次生成输出逐字节相同;
4. 没有 `NaN` / `inf` / 科学计数法数字;
5. 每个语义部件有稳定 id;
6. 所有几何在 `viewBox` 内(或被有意裁切);
7. 文件末尾有换行,UTF-8 无 BOM。

> 本技能不做像素级比对、不做图像识别;结构自检通过即视为“能交付”,视觉效果由人判断。
