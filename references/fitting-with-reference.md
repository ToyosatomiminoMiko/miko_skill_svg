# 只有拿到参考位图时才用的参数拟合

**默认不做拟合。** 本技能的正常流程是“人给出几何参数 → 生成 SVG”。只有同时满足
下面两条时才走拟合:

1. 手上有参考位图(或参考 SVG/更高清的原稿);
2. 位图里的形状确实是几何图形(齿轮/星形/圆弧/多边形),不是照片或手绘。

没有参考图就没有目标函数,拟合只会得到“看起来差不多”的随机参数,不划算。

## 流程(与 myama 冻结前的一致)

```
参考位图 ──> 渲染候选 SVG ──> 软覆盖光栅 ──> 指标(MSE / IoU / 双向亚像素边缘距离)
     ^                                              │
     └──────── 分阶段 Nelder-Mead 调参 <────────────┘
```

要点:

1. **先定结构,再拟合数值**:先手工/按几何关系确定“由哪些图元组成、哪些参数可调”,
   拟合只调数值(半径、角度、间距、偏移)。结构错了,拟合救不回来。
2. **分阶段、分部件拟合**:花环、齿轮、结、轮廓各拟各的,最后只调部件间偏移;
   一次全参拟合维度太高,容易卡在局部极值。
3. **软目标优化,硬目标验收**:优化用像素级软覆盖 MSE(可微、平滑);验收用
   IoU + 双向边缘距离(对最终观感更诚实)。只看 MSE 会把参数带偏。
4. **有理有据地停**:分辨率是上限,指标进入平台期就停;继续调是过拟合到压缩噪声。
5. **参数进常量文件,产物进版本库**:拟合结果写回 `constants.py`(唯一调参入口),
   重新拼装后 sha256 应稳定;手动改过的部件要单独标出来,不要混进拟合参数。
6. **手改回流必须显式**:如果某个部件是人工在编辑器里改的,拼装时要显式读取并标注;
   不要“文件存在就优先”这种隐藏默认。

## 什么时候该停下来人工改

- 拟合指标进入平台但某处边缘仍差 1–2px:继续拟合收益递减,人工改轮廓点更快;
- 位图本身模糊/压缩噪点重:目标是“人眼看起来对”,不是“逐像素相等”;
- 形状本来就不是几何图形(手绘曲线、文字):直接人工描,别拟合。

## 本技能不内置拟合代码

本仓库不带渲染/量测/拟合脚本:那些属于“有参考图时的专项工作”,需要时从冻结的
myama 仓库取现成实现(它在 `miko_wiki_resource/fitting/` 下,已停止演进),
按上面的流程用,结果只回写本范例的 `constants.py`。
