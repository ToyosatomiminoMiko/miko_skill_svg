# 观察记录(草稿本,不是规则集)

本文件只收「可能只是偶然」的发现,并显式标记其状态. **它不是操作指令**:`SKILL.md` 与
`references/` 正文不得引用 `[待验证]` 条目来指导行为;只有晋升为规律的内容才写进那些地方.

## 状态标记

| 标记 | 含义 |
| --- | --- |
| `[待验证]` | 只出现过一次,或只在单个任务/环境里成立;默认按偶然处理,不得当规则用 |
| `[已复现]` | 在 >=2 个相互独立的任务里复现,可以讨论晋升 |
| `[已晋升]` | 已写进 `SKILL.md` / `references/` / 代码;注明去向 |
| `[已证伪]` | 后来发现不成立;保留原因,避免重新踩坑 |

晋升门槛见 `SKILL.md` 的「自我演进」:复现 >=2 次、技能自检可验证、或外部硬约束并附来源.
