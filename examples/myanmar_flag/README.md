# myanmar_flag —— MNTJP 党旗重建(几何优先范例)

用 `svgkit` 的简单图元重绘 800x532 的 MNTJP(缅甸民族真理与正义党)党旗:
红底 + 白色花环 / 齿轮 / 底部结 / 缅甸国土轮廓。

## 运行

```sh
cd examples/myanmar_flag
python3 build.py                    # 写 ../../assets/flag.svg 与 ../../assets/emblem.svg
python3 build.py /tmp/flag.svg      # 只写整旗到指定路径
```

只需要 Python 3.9+ 与标准库,无第三方依赖。

## 结构

| 文件 | 内容 |
| --- | --- |
| `constants.py` | 全部数值参数(尺寸/角度/半径/偏移/颜色),唯一调参入口 |
| `wreath.py` | 花环: 6 枚麦穗 = 12 粒麦子(每粒一个多边形) + 2 枚顶端橄榄(两段圆弧 path) + 6 道芒(圆弧描边) |
| `gear.py` | 齿轮: 完整齿形与内孔,被国土轮廓压出的两处缺口把齿圈剪成简单多边形,无 mask |
| `root.py` | 底部结: 两根枝棒(多边形) + 圆角矩形结(`<rect rx>`) |
| `map.py` | 国土轮廓: 采样点列缩放/旋转后的单个多边形 |
| `build.py` | 拼装: 红底 `<rect>` + 四个 `<g transform>` 部件层 |

四个部件都输出**设计单位、局部原点**的图元;`build.py` 用
`translate(原点) scale(1/4.3088)` 落到 800x532 旗面。设计单位沿用 myama 阶段的口径
(1 参考像素 = 4.3088 设计单位),所以部件可以单独预览,不会把坐标换算写死在几何里。

## 来源与冻结

几何参数来自用户自己的 myama 仓库(`/mnt/IVSTINIANVS/__resources_wikipedia/myama`),
那是从 800x532 位图逐像素拟合出来的结果。该仓库已冻结:不再拟合、不再维护,
参数作为**冻结输入**原样沿用,本目录只负责用图元重画。

因此:

- 参数相同、形状等价,但**不追求**与旧 `shapes/flag.svg` 逐字节一致;
  旧产物里大量使用 `<path>` / `<mask>` / 采样圆角矩形,这里换成 `<polygon>` /
  `<rect rx>` / 真圆弧,元素结构会不同;
- 不做像素比对、不做拟合回归: 没有参考图就没有验收指标,是否满意以人眼打开 SVG 为准;
- 若以后拿到更清晰的官方稿,再按 `references/fitting-with-reference.md` 的流程
  更新 `constants.py`(只在有参考图时做)。

## 与旧产物的已知差异

- 齿轮: 旧产物用"完整 path + 两处 mask 缺口";这里用切边点列把齿圈拆成简单多边形,
  缺口边界直接是多边形边,不再引用 mask。
- 结: 旧产物把圆角矩形采样成多边形并入 `root_geometry()`;这里改成真正的 `<rect rx>`,
  圆角由渲染器解析,形状更干净(数值参数不变)。
- 根部: 旧仓库的最终 `shapes/flag.svg` 用的是人工手改过的根部(`root-edit.svg`)并把手改臂里
  自带的旧结放大 `COMPOSE_KNOT_SCALE=1.15` 盖住肩部;本范例只用 `root_fit` 拟合出的
  参数化根部(两段臂 + 填坑 + 结),不使用手改文件,所以结按 `ROOT_KNOT_*` 原值绘制、不乘 1.15。
  这是"纯参数重建"和"手改稿重建"的口径差异,不是参数错误。
- 麦穗/橄榄/芒: 几何公式与参数照搬,但输出从 path 字符串改成 `<polygon>` / 圆弧 `<path>`。
- 手改回流(旧仓库的 `root_edited.svg` 流程)不迁移: 本范例只做参数化重建,
  不接受手工改过的 SVG 覆盖生成结果。
