# OGAS 徽标重建(位图参考 → 45° 等腰梯形)

960×720 纯黑底,中央一处徽标:**4 个白色 chevron(箭头/雪佛龙)+ 3 块彩色图形**,
共 11 个 `<polygon>`,没有 mask、没有复合 path、没有渐变。

```sh
python3 build.py                  # -> skills/assets/ogas_logo.svg
python3 build.py /tmp/ogas.svg    # 写到指定路径
```

## 结构(先结构,后数值)

| 部件 | 是什么 | 组成 |
| --- | --- | --- |
| 外圈 4 个白色 chevron | 顶点指向正 N/E/S/W,离中心 215 | 每个 2 根独立臂(中间 2px 折缝),共 8 块 |
| 绿 | 指向西北(−45°)的 chevron → 两臂变成横/竖,呈 "Γ" | 1 块(两臂贴合,合成 V 形) |
| 蓝 | 指向正西(270°)的 chevron,顶点在中心偏右 | 1 块 |
| 黄 | 指向正北(0°)的 chevron,顶点在中心偏下 | 1 块 |

每一块都是**等腰梯形,底角 45°**:一条腰平行、一条腰垂直于 chevron 的对称轴,两条底边都
落在 45° 方向上。所以只要 5 个参数就能定一根臂(见 `parts.py`):

```python
parts.chevron(apex, rot_deg, leg, reach, gap=0)
#   apex  顶点坐标(局部坐标 = 相对徽标中心)
#   rot   朝向: 0°=正上, 90°=正右, 180°=正下, 270°=正左, 对角线用 ±45
#   leg   臂厚 × sqrt(2) = 端面斜切边长 = 梯形两腰
#   reach 顶点沿对称轴到臂末端面的轴向距离(不是臂长)
#   gap   两臂间的折缝; >0 输出两根梯形, =0 输出合成后的 6 点 V 形
```

外圈 4 个 chevron 是**同一份几何绕中心每 90° 旋转**出来的,所以常量文件里只有一份外圈参数。

## 参数来源(1 轮拟合)

1. `scripts/fit.py` 跑一遍参考位图:按亮度/饱和度取前景 → 4 邻接连通域 → Moore 轮廓 →
   RDP 简化,拿到 11 个色块的多边形顶点与像素面积(顺带把右侧俄文标题当成小块滤掉);
2. 对每个色块**逐行扫描** min/max x,把 45° 边与竖直/水平端面的常数项读出来
   (比 RDP 顶点更准,因为 45° 边的阶梯会被最小二乘性质“抹平”);
3. 把这些常数归到同一套 45° 网格上(见下表),用 `parts.chevron` 重新生成,
   并做了一次数值自检:把模型多边形光栅化后与位图色块比 IoU,平均 0.90(见下)。

| 参数 | 位图量值 | 采用值 |
| --- | --- | --- |
| 徽标中心 | (454.5, 355.5) | 同 |
| 外圈顶点半径 | N/E/S/W 均 215 | 215 |
| 外圈臂厚 × √2 | 31 | 31 |
| 外圈顶点→末端面 | 89~92(N=92) | 90 |
| 外圈两臂折缝 | 2px | 2 |
| 内圈臂厚 × √2 | 33 | 33 |
| 内圈顶点→末端面 | 93 | 93 |
| 绿: 顶点 / 臂厚√2 / reach | (−104,−106) / 32.5 / 128.7 | 同 |
| 蓝: 顶点 / 朝向 | (12,−1) / 西 | 同 |
| 黄: 顶点 / 朝向 | (−2.5,14.5) / 北 | 同 |

## 已知偏差(有意保留)

- **参考图本身不是严格四重对称**:它的 N/S 两个 chevron 整体比“对称布局”左偏 3~5px
  (E/W 两个只差 ~1px)。本重建坚持**精确四重对称**,所以逐块 IoU 在 0.70~0.98 之间、
  平均 0.90——差异主要是这 3~5px 的整体平移,不是形状不对。
- 参考图背景是径向渐变,按要求换成纯黑(`constants.BACKGROUND`),几何不受影响。
- 右侧俄文标题(`обще…государственная…`)按要求不画;所以徽标保持原来的偏左位置,
  没有挪到画布正中(要挪只改 `constants.CENTER`)。
- 参考图各色块是纯色平面(取样中位数: 白 `#cecece`、绿 `#70ba6b`、蓝 `#6a83bb`、
  黄 `#babb69`),没有渐变/描边/阴影,所以这里也不加。
